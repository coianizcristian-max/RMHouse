AGGIORNAMENTO N 018 — RMHouse
L'occhio per mostrare la password

QUERY DA ESEGUIRE
-----------------
Nessuna.

FILE DA COPIARE
---------------
app/login/page.js        sostituito
app/globals.css          sostituito

Poi: git add . && git commit -m "Aggiornamento 018" && git push

COSA CAMBIA
-----------
Nella pagina di accesso dello staff, dentro il campo Password c'e' ora
il tastino con l'occhio: toccandolo la password diventa leggibile,
ritoccandolo torna nascosta. L'icona cambia (occhio sbarrato quando e'
visibile) e ha le etichette giuste per chi usa il lettore di schermo.

NOTA
----
Nell'area dei clienti non serve: li' si entra con il link mandato per
email, senza password.
